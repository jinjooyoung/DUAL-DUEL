## 게임 소개

"적의 행동까지 내가 통제한다!"

**DUAL DUEL**은 기존 덱빌딩 게임의 높은 진입장벽을 낮추고, 빠른 템포와 직관적인 전략성을 강조한 캐주얼 덱빌딩 전투 게임입니다. 

"하이퍼 팝 사이버 판타지(사이버펑크 SF)" 세계관을 배경으로 하며, 플레이어는 적들을 해킹하여 컨트롤하는 독특한 컨셉을 경험하게 됩니다. 

## 주요 특징

* **혼합 행동 덱 시스템**: 플레이어와 적의 행동 카드가 유저의 덱에서 함께 등장하는 고유한 구조
* **슬롯 기반 카드 배치 전투**: 정해진 슬롯 순서에 맞게 카드를 전략적으로 배치하여 진행되는 턴제 전투
* **낮은 진입장벽과 직관성**: 카드 효과를 단순화하고 상황 중심의 선택을 강조하여 누구나 쉽게 접근 가능
* **감각적인 세계관**: 키치하고 하이퍼캐주얼한 아트 스타일과 빠른 템포가 결합된 캐주얼 플레이 경험

## 개발 팀 소개 및 담당 업무

팀 내에서 명확한 역할 분담을 통해 완성도 높은 게임을 목표로 개발하고 있습니다.

### [진주영] (메인 개발자)
* **기획**: 게임 시스템 설계, 카드 효과 및 밸런싱, 레벨 디자인
* **프로그래밍**: Unity 기반 클라이언트 구현, 카드 배틀 메커니즘 개발, UI/UX 시스템 구현
* **디자인 및 와이어프레임**: 게임 화면 구성, UI 와이어프레임 설계 및 아트 가이드라인 수립
* **프로젝트 관리**: 개발 문서 작성 및 정리, 마일스톤 및 일정 관리, 팀 리딩

### [김유] (그래픽 디자이너)
* **아트 & 비주얼**: 하이퍼 팝 및 키치 스타일의 게임 원화, 캐릭터 디자인
* **게임 리소스 제작**: 카드 일러스트, 배경 오브젝트, UI 에셋 및 비주얼 리소스 전반 담당
